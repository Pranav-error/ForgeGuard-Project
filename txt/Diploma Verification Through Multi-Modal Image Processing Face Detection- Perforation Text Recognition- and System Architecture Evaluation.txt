• Face Detection: The system detects and locates faces
within an image or video stream by scanning the input
data to identify regions of interest (ROI) corresponding to
human faces. This process is carried out using advanced
algorithms, often based on cascading classifiers or deep
convolutional neural networks (CNN). As demonstrated
in [3], a CNN cascade for face detection was developed
with a strong discriminative ability, leading to highly
effective performance.
• Feature Extraction: After detecting faces, the next vital
step is extracting unique facial features. This process
converts the facial image into a set of numerical
representations called feature vectors. Deep learningbased feature extraction using Convolutional Neural
Networks (CNNs).
• Verification or Recognition: The final stage involves
matching extracted facial feature vectors with a database
using methods advanced Deep Learning techniques are
also employed for identity verification. The system
assigns an identity label based on the closest match,
determined by the chosen distance metric or classification
method.

Abstract—This research presents a novel approach to
digitally verify diploma authenticity using a combination of
Siamese Neural Network (SNN) for face verification and
YOLOv8 for text perforation detection. The SNN model,
utilizing a binary cross-entropy loss function, successfully
minimized the loss value from 0.169 to 0.0025 by the sixtieth
epoch, achieving an accuracy of 0.98. This demonstrates the
model's high proficiency in differentiating between anchor and
positive/negative images. Additionally, the YOLOv8 model
achieved a mean Average Precision (mAP) of 0.93 at a 0.5 IoU
threshold, further enhancing the precision of text perforation
detection. This integrated system offers a robust and efficient
method for ensuring the authenticity of diploma documents,
contributing significantly to digital document security and
forgery prevention. The research supports the implementation
of deep learning in official document verification.
Keywords—diploma document, face verification, perforations
detection, machine learning, deep learning.

II. PROPOSED METHOD
This study presents two methods for verifying diploma
authenticity. The first method uses face-based verification,
where the Haar cascade algorithm detects facial images from
diploma documents from the different levels in Table 1.
Features are extracted using a Siamese Neural Network
(SNN) and compared with official student photos from prior
academic records, such as junior and senior high school
images. Binary cross entropy loss is then used to evaluate the
accuracy of the matches. The second method focuses on
detecting and validating perforated text, typically located in
the center-right section of the diploma, which includes key
details like the year of issuance and education level (e.g., "D2020" for primary education, "M-2020" for secondary
education). The YOLO object detection model identifies the
perforation. The results are combined to enhance the overall
accuracy and reliability of the diploma verification system.

In a Siamese Neural Network (SNN), two facial images
pass through identical networks with shared weights,
generating feature embeddings (Features 1 and 2) that capture
key facial characteristics, as shown in Figure 2. A classifier
then compares the features using a distance metric, like
Euclidean distance, to assess similarity. If the distance is
below a set threshold, the faces are classified as the same
person; otherwise, they are different. This architecture excels
in facial verification by effectively learning and comparing
image similarities.

Precision is the ratio of True Positives (TP) to
the sum of True Positives and False Positives (FP), calculated
as Precision = TP / (TP + FP). It reflects how many of the
model’s positive predictions are correct. Recall, or
Sensitivity, measures the model's ability to identify all actual
positives, calculated as Recall = TP / (TP + FN). It evaluates
how well the model detects true positive cases.

3) Training Model
The YOLOv8 model is trained using the free

collaborative platforms. This training consists of several
cycles, known as epochs, with the entire dataset being
processed over 137 epochs.

accuracy rate, confusion matrix, and Mean Average Precision
(mAP).

3) Confusion Matrix
A confusion matrix is used to assess the
performance model. In binary classification, it includes True
Positives (TP), True Negatives (TN), False Positives (FP),
and False Negatives (FN), representing the model’s correct
and incorrect predictions. Key metrics like accuracy,
precision, and recall are derived from it. For multi-class
classification, the matrix expands to an n x n table, where n
is the number of classes. This is crucial in cases where certain
errors have more significant consequences than others.[14].

Mean Average Precision (mAP) is an essential
metric used to evaluate the effectiveness of object detection
models across various classes. It is calculated by
determining the average precision for each category. It is
derived by evaluating the area under the precision-recall
curve and is analyzed using the Intersection over Union
(IoU) metric. Once the average precision for each class is
determined, the mean of these values is computed to yield
the overall performance score.

Triplet Loss in a Siamese Neural Network minimizes the
distance between similar face embeddings (Anchor and
Positive) while maximizing the distance between dissimilar
ones (Anchor and Negative). The network processes three
inputs, Anchor, Positive, and Negative, through shared
weights to generate feature embeddings. The Anchor is the
reference image, the Positive is from the same person, and the
Negative is from a different one. The objective is to make the
Anchor-Positive distance smaller than the Anchor-Negative
distance by a set margin, enhancing face recognition
accuracy.
