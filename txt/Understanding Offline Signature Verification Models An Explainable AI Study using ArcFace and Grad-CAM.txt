Abstract—Verifying handwritten signatures is a challenging
task because people do not sign exactly the same way every
time. Small changes in how a person writes like pressure,
speed, or the way they move the pen make it hard for systems
to tell real signatures from fake ones. In this study, propose an
effective method for offline signature verification (OSV) using
ArcFace, a loss function originally developed for face
recognition. While ArcFace has been explored in a few existing
OSV studies, our work is distinct in its focus on writer
independent verification, combined with explainable AI using
Grad-CAM. This pairing not only improves verification
performance but also adds transparency to the model's
decisions an area still underexplored in the OSV domain.
Unlike traditional Siamese or triplet-based models that
compare signature pairs, our approach treats each writer as a
separate class and trains a classification-based model. This
method makes training more stable, avoids the need for
manually creating sample pairs, and allows the model to learn
stronger writer-specific features. Work trained our model on a
large offline signature dataset with 486 writers and evaluated it
on a completely separate test set containing unseen writers.
The best model achieved a high ROC AUC score of 0.9194 and
an Equal Error Rate (EER) of 0.1762, indicating its strong
ability to distinguish genuine from forged signatures. To
improve transparency and trust in the system, used GradCAM to generate heatmaps that show which parts of the
signature the model focuses on when making a prediction.
These visual explanations revealed that the model pays close
attention to distinctive curves, loops, and intersections that are
important for verifying signatures. Our approach shows that
ArcFace is not only effective but also interpretable for offline
signature verification. The system is suitable for real-world
applications where both accuracy and explainability are
critical, such as in banking, legal documents, and forensics.

A. Data Collection and Preprocessing
The dataset used in this study was formed by combining
multiple publicly available offline signature datasets. These
include CEDAR (versions 1 and 2), Signature Matching,
Handwritten Signature Datasets and a completely separate
test dataset named signature-verification-dataset briefly
listed in below Table I. All datasets were accessed from
Google Drive and preprocessed before use [15]. The
preprocessing steps ensured consistency in image quality
and format. All signature images were converted to
grayscale and resized to 128x128 pixels. Although explicit
normalization was not applied separately, normalization
effects were handled using Batch Normalization layers
within the network. After processing, the images were saved
along with their [16] corresponding writer IDs and labels
(genuine or forged) to Google Drive for efficient access
during training.

II. RELATED WORKS
Work will review related work in detail and show

A. Deep Learning for Signature Verification
Older OSV systems relied on fixed rules or features
chosen by experts. These included shape, angle, pressure
points, or stroke direction. But such features did not work
well when writers changed their style or when scanned
signatures were noisy. Deep learning made this task easier.
[8] was one of the first popular models, using a Siamese
network to learn whether two signatures match. Later [9]
used attention maps and triplet loss to improve accuracy.
[10] used local and global features and deep metric learning
for better results. However, these methods are harder to train
and require carefully chosen signature pairs. Some models
tried simpler ideas. Used MobileNet and selected only the
best features for classification, getting high accuracy [11].
But these models don’t explain how decisions are made and
are not always reliable with unseen writers.

B. Data Splitting Strategy

Face recognition models have helped improve
verification tasks in general. FaceNet used triplet loss, while
ArcFace and CosFace introduced margin-based losses to
push different classes apart in feature space [12]. Sub-Center
ArcFace further improved ArcFace by handling class
imbalance. Even though these methods worked well in face
tasks, they were not often used in signature verification. In
this work, show that ArcFace works very well for writerbased classification. It allows the model to learn distinct
patterns for each writer and gives better performance than
distance-based losses.

To ensure the model could generalize to new writers, a
writer independent splitting strategy was used. Writers in
the combined dataset were split into training and validation
groups using an 80:20 ratio. Importantly, a separate test
dataset containing entirely different writers was reserved for
final evaluation. This separation helps test the system's
ability to verify signatures from writers it has never seen
during training.
C. Model Architecture
At the core of our system is a Convolutional Neural
Network (CNN) built to learn strong and meaningful
features from signature images. This base network was
improved step by step through experiments and testing
different designs. It follows a sequence of layers that are
commonly used in deep learning for image-related tasks.
The network begins with several Conv2D layers that apply
filters to detect important patterns in the signature, such as
curves, edges, and textures. Each convolutional layer is
followed by a MaxPooling layer, which reduces the size of
the feature maps. This makes the model more efficient and
helps it ignore small shifts or changes in the signature's
position or size [17]. After each convolution, a Batch
Normalization layer is added to keep the training stable and
improve accuracy. These building blocks Conv2D,
MaxPooling, and Batch Normalization are repeated multiple
times to extract deeper and more abstract features as the
network goes deeper. Once these features are extracted, a
Flatten layer converts the 2D feature maps into a 1D vector.
This is passed to a dense layer that outputs a 128
dimensional vector. This vector acts as the signature’s

E. Model Evaluation
After training, the model was evaluated using the
separate test dataset. This step tested the system's ability to
perform signature verification for unseen writers. The
evaluation process began with generating 128 dimensional
embeddings for each signature in the test set. Then,
signature pairs were formed some from the same writer
(genuine-genuine pairs) and some from different writers
(genuine-imposter pairs). For each pair, cosine similarity
was calculated between the embedding vectors. Based on
the similarity scores and true labels, two main metrics were
used: ROC AUC (Receiver Operating Characteristic Area
Under Curve): Measures how well the model distinguishes
between genuine and imposter pairs across thresholds.
Approximate Equal Error Rate (EER): The point where the
false match rate equals the false non-match rate. These
metrics help assess the verification quality and robustness of
the model.

To understand what the model focuses on when

the model considered important for classification. This adds
a layer of transparency and helps build trust in the system,
especially in sensitive use cases like banking or document
authentication.

E. Insights from Explainable AI (Grad-CAM)
To gain a better understanding of how the model
interprets signature images during verification, we applied
Grad-CAM (Gradient-weighted Class Activation Mapping)
to selected test samples. Grad-CAM generates visual
heatmaps that highlight the most influential regions in the
input image areas that contributed most strongly to the
model’s predictions. These heatmaps offer a visual
explanation of the internal decision-making process, which
is often considered a black box in deep learning models.
The visualizations revealed several consistent patterns. For
genuine signatures, the model typically focused on
distinctive structural elements, such as unique loops,
curves, stroke thicknesses, and crossing points particularly
in the central region of the signature, where writing
pressure and control are usually most stable. These features
are often difficult for a forger to replicate consistently,
which makes them highly valuable for distinguishing
genuine signatures from forgeries. In contrast, for forged
signatures, the attention maps were more scattered. The
model appeared to either focus on less defined strokes or
sometimes even ignored noise or unnatural artifacts
introduced during imitation. In several cases, the heatmaps
showed reduced focus on the beginning or end of the
signature, likely because these regions tend to vary even in
genuine samples and carry less discriminative information.
These observations align well with human reasoning:
complex or personalized parts of a signature are naturally
more informative than simple straight lines or repeated
patterns. By confirming that the model pays attention to
such regions, Grad-CAM helps validate the reliability of
the learned features. Importantly, this layer of visual
explainability increases trust in the model’s predictions
especially in sensitive use cases like banking, legal
verification, and forensic document analysis. Stakeholders
can better interpret the outcome and have more confidence
in deploying such a system in real-world environments
where interpretability is just as critical as accuracy.

D. Demonstration
To understand how well the model works on new writers it
hasn't seen before, tested it using signatures from one such
writer in the test set. This writer had both real and forged
signatures. Work picked one real and one forged signature
and passed them through the trained model, which
converted them into numeric representations (embeddings).
Then, work measured how similar they were using cosine
similarity. Based on the earlier decided threshold for
deciding if two signatures are similar, the model classified
this pair as a forged pair. This prediction was correct,
showing that the model can recognize forged signatures
even from a writer it hasn't seen during training.

V. CONCLUSION AND FUTURE DIRECTION
In summary, the proposed ArcFace-based CNN model
performs strongly in the task of offline signature
verification, especially when verifying signatures from
unseen writers. The key results, with a ROC AUC of 0.9194
and an EER of 0.1762 demonstrate that the model is both
accurate and generalizable. The iterative training and
optimization process significantly contributed to achieving
these results. Moreover, the use of Grad-CAM helped verify
that the model's attention aligns with human-understood
signature features, increasing the explainability and
trustworthiness of the system. While the current system
performs well, there is room for further improvement.
Future work could focus on: Expanding the dataset to
include more writers and cultural variations in signatures.
Exploring alternative explainability techniques like LIME or
SHAP. Enhancing forgery detection by incorporating pen
pressure or dynamic features (in online signatures).
Converting this system into a mobile or web application for
practical deployment.
