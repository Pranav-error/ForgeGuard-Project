Abstract— Signature verification is also one of the most
popular forms of biometric authentication, particularly when
there is offline authentication, e.g. cheques, forms, letters and
official documents. Accurate verification is essential since the
signature of each person is unique, and this can help stop
fraud. Nonetheless, the loss of human verification is usually
susceptible to mistakes and irregularity. A hybrid solution to
the offline signature verification through Convolutional Neural
Networks (CNN) that integrates with Autoencoder-based data
augmentation to enhance the detection of fake signatures is
presented in this paper. A Writer-Dependent model is applied
in which random distortions are produced on authentic
signatures with the help of an autoencoder to produce
counterfeit signatures. The CNN classifier is then trained using
them. The paper describes the pre-processing procedures
applied to the signature images, and gives experimental results
under different conditions of varying the number of training
samples. In the Persian signature dataset, the model was
trained on 22 genuine images per user and its average test
accuracy was 83%. At the lower reduction in the number of
real training samples (9), accuracy was decreased by 9.4
percent, which indicates that the amount of training data does
affect verification performance.

I.

INTRODUCTION

Handwritten signature is still used as the most popular
biometric identifier for personal identification in banking,
legal and administrative service. Signatures are used in a
large number of cases in financial transactions, including
checks, credits and legal contracts or agreements, even in the
age digital transformation due to their simplicity and social
acceptance. But handwritten signatures are extremely
vulnerable to fraud and abuse, potentially leading to costly
financial and legal repercussions. Hence, it is critical to
develop robust and automated signatures verification system.
The signature verification is a narrow pattern recognition
task, the problem of learning discriminative features from
real-signed signatures to separate them to fake-signed ones.
According to the verification, methods can be divided into on
and offline. The online methods are based on dynamic
features of the signing process including pen pressure,
velocity, direction and stroke order whereas the offline ones
use only static signature image. Because offline signatures
are deprived of temporal information and have irregular
intra-class variation, verifying them is inherently more
difficult. However, offline signatures are still in vast use

Conventional image processing and statistical feature

In recent years, due to the rise of machine learning and
especially deep learning fields, new tools for automated
(signature) image feature extraction and description have

spatial hierarchies of features. Similarly, autoencoders have
also demonstrated their success in unsupervised feature
learning and data augmentation due to generation of realistic
augments of input data.
This paper proposes a hybrid framework for the
Autoencoder CNN over offline signature verification. The
automatic encoder creates distorted versions of real
signatures which appear like forgeries. This makes the CNN
classifier stronger during training. The staff of CNN has
been taught to tell the difference between real and fake
signatures based on the writer. The suggested technique was
tested with the Persian offline signature dataset. While
trained alongside 22 real signatures, the algorithm had an
average accuracy for 83%. Whenever the number of real
samples was cut down to 9, the accuracy dropped by only
9.4%. These results show that the recommended hybrid
framework could make offline signature verification methods
more accurate and useful in general.

difficult, mainly because handwriting varies naturally from
person for person; a single individual can't always produce
the same signature.

and test the model. The LSTM model accomplished

innovative feature set predicated upon the quasi-straightness
about boundary pixel runs over signature verification. The
suggested method used directional codes compared to
signature boundary pixels to find quasi-straight line segments.
These features did a great job of capturing the balance
between straightness as well as small curvature, which made
the verification system more reliable. The authors utilized an
SVM classifier and exhibited enhanced performance upon
standard datasets, including CEDAR and GPDS-100,
surpassing multiple state-of-the-art methodologies [20].
In [3], a new online signature verification system was put
forth. It used fuzzy modeling to look at both the shape and
the dynamic features found in digital signature data [4]. The
signature divided at its geometric extremes, and fuzzy logic
was used to extract and model features over each segment.
We used Dynamic Time Warping (DTW) to line up two
signature samples to determine the correspondence between
segments. A threshold that depended on the user was then
used to decide when a test sample had been real or fake.
Validation experiments on benchmark datasets SVC2004 and
SUSIG confirmed the efficacy associated with the proposed
fuzzy-based method for both skilled as well as random
forgeries [3,29].
Another study proposed a new way to verify identity
using dynamic signature partitioning, that takes into account
things like pen speed and pressure over time [3,29]. This
method makes verification more effective by breaking the
signature up into several parts, each of which represents a
different time when it was signed. A neuro-fuzzy
classification system was made using fuzzy set theory, which
made it possible to make flexible and understandable
decisions. The SVC2004 and BioSecure databases were used
to run simulations that showed the method could work well
for high verification accuracy.

In addition, [5] introduced an improved signature
partitioning method that uses hybrid partitions in order to test
signature analysis more precise [6-8]. The partitions were
made by putting together vertical and horizontal parts that
comprised the signature [9-11]. The vertical parts showed the•
beginning, middle, and end of the signing, whereas the top
and bottom parts showed areas in which the pen moved at
different speeds and pressures [3,4,12,13]. The suggested
algorithm gave priority to stable signing areas, which made it
more robust and improved the performance of verification
[14-18]. The method was tested with the MCYT-100 and
BioSecure datasets, which showed that it can improve the
accuracy of dynamic signature verification systems [19, 20].

F. Algorithm
1. Input:
• Genuine and forged signature images for each writer
• Hyperparameters (image size, learning rate, epochs,
batch size, etc.)
2. Output:
• Trained writer-specific verification model
• Classification result: Genuine or Forged
3. Algorithm Steps:
• Collect per-writer genuine and forged samples; divide
into training, validation, and test sets.
• Preprocess all images (convert to grayscale, blur, apply
Otsu binarization, resize, and normalize).
• Train an Autoencoder on genuine signatures to learn
reconstruction patterns.
• Generate synthetic forged samples by perturbing latent
vectors and applying minor distortions.
• Train a CNN feature extractor on genuine, synthetic, and
forged samples.
• Concatenate Autoencoder latent features and CNN
features to form a hybrid representation.
• Train a binary classifier using the hybrid features (label
1 = genuine, 0 = forged).
• Determine the optimal decision threshold where false
acceptance rate ≈ false rejection rate (EER point).
• Freeze the trained model parameters and threshold for
each writer.
• During testing, preprocess the input signature and
extract hybrid features.
• Classify using the trained model: if score ≥ threshold →
Genuine, else → Forged.
• Compute and report evaluation metrics (Accuracy,
Precision, Recall, F1-Score, and EER).

VI. CONCLUSION
The suggested offline signature verification system uses a
mix of Convolutional Neural Networks (CNN) and
Autoencoders to identify strong features that can tell the
difference between real and fake signatures. We used
classical classifiers like Support Vector Machine (SVM) and
K-Nearest Neighbors (KNN) to correctly sort signatures
based on the features we learned. Tests showed that the
system was reliable and strong because it had high accuracy,
low equal error rates, and balanced precision, recall, and F1scores across benchmark datasets. A user-friendly Flaskbased interface alongside built-in secure authentication
makes the system even easier to use and safer, making it
ready for utilization in the real world. When compared to
more advanced methods, the proposed framework shows that
it works well. This sets a strong base for future
improvements, such as adding more data and making it
possible to verify signatures in real time.
