Abstract— The advancement of technologies nowadays cause
image digitally to become essential as an official document
many available applications used for image editing. Those
applications have become a threat to detect image authenticity
when dealing with an abundance of digital image evidence in
cyber court. Hence, many researchers realize the
importance of image authentication fields as deep fake is a
powerful weapon for spreading misinformation on the digital
platform. Deep learning has known to obtain relevant attributes
automatically in placing handcrafted features in a deep
network against other single-layer networks. The objective of
the research is to compare two models from Convolutional
Neural Network (CNN), which are VGG19 dan ResNet50 in
deep learning with transfer learning for image fake
detector. A total of 1500 random images consisting of 450
forgery images from the IEEE Image Forensics Challenge in
2013 were tested on the splicing technique. From this
research, we used two transfer learning techniques to
identify tamper images from image splicing. Based on model
VGG16 and ResNet50 transfer learning, the accuracy achieved
about 94.65% and 95.08%, respectively.
Keywords—deep learning, neural network, deep fake a transfer
learning

I. INTRODUCTION

uploaded. It has proven that social media tends to cause body
image concerns, which lead to issues like eating disorders and
photoshopping images (Bell, 2016). More editing applications
emerge, and the amount of altered digital images increases on

LITERATURE REVIEW

Digital image forensic (DIF) is a discipline that conducts
image processing and analysis on digital images through tools
or techniques to identify if there are any elements of
alterations (Redi et al., 2011; Mizher et al., 2017;2019,). DIF
also consists of identifying the timestamp and location of the
device that produces the edited image. Obtaining that
information is difficult because image tampering tends only
to leave a slight trace, which makes tracking difficult.
Tampering an image occurs when the semantic content of an
image has changed due to an addition or removal parts of an
image (Redi et al., 2011). Detection of those tampered

authenticity of a digital image. There are three main methods
for the passive approach, which are copy-move, image
splicing, and image retouching.
A. Deep Learning Application in Forgery Detection
Based on all the forgery detection techniques stated, those
techniques utilize statistical data and statistical models.
However, in this paper, a deep neural network is being used
to conduct the detection. Deep learning has been known to
have an impressive performance in object detection and
obtained a very high accuracy. Currently, there are several
efforts to integrate deep learning and digital image forensics
(DIF). Yuan Rao proposed a work that uses a deep learning
approach to conduct splicing and copy-move detection (Rao
& Ni, 2016). The proposed convolutional neural network
(CNN) contains 8 convolutional layers, 2 pooling layers, and
a fully connected layer with a softmax classifier that takes
RGB color images as an input. The first layer contains 30
basic high-pass filters used in the spatial rich model (SRM)
is applied to suppress the effect of complex image content.
Compared to other CNNs used in other works, this neural
network only exploits one fully connected layer due to the
lack of the number of the training set. The modified CNN
demonstrates outstanding performance in detecting forgeries
on digital images.
Moreover, Weize Quan et al. proposed another work that
exploits CNN to obtain a high accuracy model for colorized
image detection (Quan et al., 2019). They have decided to
develop an “end-to-end” framework based on CNN to
distinguish between natural and colorized images. This
framework is also known as a unified framework where both
recurrent neural networks (RNNs) and CNN's are combined
(Wang J. et al., 2016). Thus, this framework learns the
embedded joint image-label and model the label cooccurrence dependency in a joint label embedding space. The
base network of CNN has improved by adding a new branch
to attain better performance in the generalization capability.
Another step in improving forensic performance is by
including an additional auto-constructed negative sample into
the original training dataset. Further and enhanced training of
the network is then conducted for better generalization
performance. With the presence of several precaution steps in
improving generalization, the output model shows stable

performance in handling blind detection scenarios; however,
this approach reduced the classification accuracy slightly.
Another approach was conducted by Jason Bunk et al.,
which utilizes two methods to perform forgery detection
(Bunk J. et al., 2017). The first step uses an end-to-end
framework based on Radeon transform and deep learning,
which localized the manipulated region. The following
method applies resampling features from probability-maps
and combining it with Long short-term memory (LSTM)
model to classify altered patches. The resampling method
requires interpolation, which presents periodic correlations
among pixels (Mohammed et al., 2018). A linear or a cubic
model can detect this correlation. But, in this work, a linear
approach is being used. This work intended to identify the
accuracy of both methods and comparing the results. It is safe
to say that both methods perform well in detecting
manipulated regions by utilizing resampling features.
B. Transfer Learning
In this work, the well-known deep learning technique, namely
transfer learning, is used to develop the detection model. In
simpler words, transfer learning allows the current model to
learn from the previous model by transferring knowledge.
Generally, there are two types of transfer learning:
heterogeneous transfer learning and homogenous transfer
learning (Weiss et al., 2016). Heterogeneous transfer learning
is when the source project or model does not contain the same
features as the target project, while homogenous transfer
learning has the same values for both source and target
models. However, another term is present with regards to
transfer learning, which is called negative transfer. Negative
transfer happens when the knowledge transferred from the
source domain produces a negative impact on the target
source due to the level of relativity between both sources.
Thus, to obtain an accurate detection model, the transfer
learning process needs to project a positive transfer from the
source to the target model. This behavior can ensure that both
the source and the target model features are related to one
another. Deep networks such as AlexNet, ResNet, VGGNet,
Inception and Xception have been regularly utilized by
applying transfer learning.

In this study, the deep learning methods have taken
VGG16 and ResNet50 models as the study method (Sarkar
D.J, 2018). The transfer learning methods used in this study
are as follows:
- Uses the bottleneck features from the pre-training
series combine with the shallow series.
-

Performs fine-tuning on the last layer combine with
the superficial network (the fine-tuning model)

The usage of the final convolution layer results in VGG16
and ResNet50 is also known as the feature input to the
additional layer. The additional layer is known as the CNN
superficial layer. This shallow layer input has only one
channel—the design of the CNN shallow layer, as illustrated
in Fig. 1 in the last three layers.
The last layer selection in this study was to avoid
overfitting as the whole network on the VGG16, and ResNet
50 designs had very high entropy capacity. In this study, the
modifications to the last layer use very low learning rates so
as not to damage the other learning features.
The amount of data used is not the CASIA data set used in
previous studies. For the convolution layer, the ReLu
activation function was subsequently employed. The
activation function equated to the amount of weight that is
placed on the input to determine which input can be processed.
The use of ReLu as a function of activation in this study is
because ReLu provides a linear computational function, so
without complicated calculations, the learning model takes
lesser time for data testing or training. Layers are known as
pooling, and max-pooling layers are used as settings. This
layer functions to lower the input size by modifying the new
input scale.

V. CONCLUSION
In conclusion, the ResNet50 design produces higher
accuracy compared to VGG16. This trend appears because of
the deeper capabilities of the ResNet50 design network. At the
same time, we are testing an unlabelled data set. Incoming
Resnet can produce higher accuracy than VGG16 with a lower
loss rate than VGG16. The main reason for choosing transfer
learning in this study is that transfer learning can save time,
cost, and it is a stable model of deep learning. The use of deep
learning alone is impossible without adequate experience.
