# ForgeGuard frontend

React + Vite + TypeScript + Tailwind CSS v4 + React Router. See the repo root `README.md`'s
"The Web Frontend" section for the full writeup (pages, auth model, how it's served in
production). Quick start:

```bash
npm install
npm run dev     # dev server at :5173, proxies API calls to the backend at :8000
npm run build   # -> dist/, served by the FastAPI backend in production
```
